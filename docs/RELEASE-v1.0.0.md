# Atlante Deep Sky v1.0.0

First standalone release of the Modena deep-sky atlas.

## Download and run

Download **atlas-v1.0.0-ready-to-run.zip**, extract it, and open **atlas-v1.0.0/index.html** in a modern desktop browser. No installation, Node.js, account, API key or server is required to run the release.

The archive includes the editable source, catalogue source and software notices. Use the repository README for development instructions. Verify the archive with the attached SHA256SUMS.txt if desired.

## Features

- 248 entries, covering every Messier and Caldwell designation plus selected additional targets.
- Technical object data and source attribution.
- S30 Pro / S50 Pro native FOV overlays on DSS2 images.
- Night recommendations, useful windows and seasonal charts from Modena.
- Cardinal directions, azimuth and altitude by time.
- Circular visible-horizon filter, including ranges crossing north.
- Galaxy morphology guide.

## Limitations

- Interface in Italian; fixed observing location Modena.
- Astronomical calculations and catalogue work offline; survey and morphology photographs require internet.
- No weather forecast, telescope control, mosaic simulation or saved preferences.
- Times are sampled every 15 minutes. Scores are heuristic and do not predict image quality.
- Downloaded HTML execution on mobile depends on the operating system and browser; the release primarily targets desktop browsers.
